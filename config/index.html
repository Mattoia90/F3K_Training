F3K Training configurator

Edit the user settings of F3K_TRAINING/custom.lua. Only the values below are changed; the rest of the file is kept as is.

1. Load custom.lua

…or drop the file here

2. Radio layout

Click a control (or its label) to assign it to:
P = prelaunchM = menuS = scroll
Drawings follow the overview in the manufacturer's manual (mode 2 sticks, not to scale). Switches may differ on other hardware versions or if they were swapped: check them in the radio's hardware / switch test screen.

3. Settings

Momentary (spring-loaded) switch: hold > 0.6 s and release to launch, quick pull = landed.
A 3-position switch is mandatory: up = menu, middle = stop, down = run.
Input used to scroll the task menu (stick, pot, slider, trim or switch).
On: play the task description, then the prep countdown announces 10..1.
Off: no description, short prep time counting down from PREP_COUNTDOWN.
Range 1..10. Used only when Task description is off.

4. Save

Copy the file to SCRIPTS/F3K_TRAINING/custom.lua on the radio SD card.
